CSS Gyakorló Weboldal

A 12-16. órák tananyagainak gyakorlati alkalmazása

Typography

A tipográfia a szövegek vizuális megjelenítésének művészete. Webfejlesztésben kulcsfontosságú elemek:

  • Font-family és webfontok
  • Font-size, weight, style
  • Line-height és letter-spacing
  • Text-shadow effektusok

Színek & Átlátszóság

Színkezelés és átlátszósági technikák modern weboldalakhoz:

  • RGB és RGBA formátumok
  • Opacity tulajdonság
  • Linear gradientek
  • Színkombinációk

Box Model

A CSS box model megértése elengedhetetlen a pontos layout készítéshez:

  • Content, padding, border, margin
  • Box-sizing: border-box
  • Margin collapsing jelenség
  • Modern layout technikák

Display & Position

Elemek elhelyezése és megjelenítési módja a weboldalon:

  • Block, inline, inline-block
  • Relative, absolute, fixed
  • Z-index kezelés
  • Sticky pozicionálás

Pseudo-elemek

Virtuális elemek létrehozása ::before és ::after segítségével:

  • Dekoratív elemek hozzáadása
  • Ikonok és díszítések
  • Content tulajdonság használata
  • Animációk és effektek

HTTP Alapok

Webes kommunikáció alapjai és HTTP protokoll megértése:

  • Kérés-válasz modell
  • HTTP metódusok (GET, POST, PUT, DELETE)
  • Státuszkódok jelentése
  • Headers és Body kezelés
